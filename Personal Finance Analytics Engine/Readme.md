# Personal Finance Analytics Engine

A Python-based console application for recording, managing, and analyzing personal financial transactions.

The project provides a simple way to track income and expenses while generating useful financial insights such as total income, total expenses, balance, spending by category, monthly activity, and spending statistics.

## Why This Project?

Managing personal finances requires more than simply recording transactions. Understanding where money is coming from, where it is being spent, and how spending changes over time can help with better financial decision-making.

The purpose of this project is to build a practical financial analysis application while developing programming and problem-solving skills in Python.

Instead of using a pre-built financial application, this project focuses on building the core functionality from scratch and understanding how each part of the system works.

## What Does It Help With?

The application helps users:

* Record and view income and expenses.
* Search for transactions
* Calculate total income, expenses, and balance
* Find average, highest, and lowest expenses
* Analyze spending by category
* Track monthly financial activity
* View spending statistics
* Generate monthly financial reports
