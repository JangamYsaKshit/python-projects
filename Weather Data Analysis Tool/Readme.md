# Weather Data Analysis Tool

## About the Project

The Weather Data Analysis Tool is a Python-based console application that allows users to manage weather records and perform basic weather analysis.

The main purpose of this project is to practise Python programming concepts by building a practical application. Users can add, view, search, update, and delete weather records. They can also analyse temperature, rainfall, and monthly weather information.

This project was developed for learning and practice purposes.

## Features

The application provides the following features:

1. **Add Weather Record** – Add new weather information, including date, city, temperature, humidity, and rainfall.
2. **View All Weather Records** – Display all available weather records.
3. **Search Weather Record** – Search records using Record ID, date, or city.
4. **Update Weather Record** – Update existing weather information.
5. **Delete Weather Record** – Remove a weather record.
6. **Temperature Analysis** – Calculate average, highest, and lowest temperatures and analyse temperatures by city or date.
7. **Rainfall Analysis** – Calculate total, average, and highest rainfall and identify rainy records.
8. **Monthly Weather Analysis** – Group weather records by month and analyse monthly temperature and rainfall.
9. **Overall Weather Statistics** – Display general statistics about the available weather records.
10. **Generate Weather Report** – Generate a summary report using the available weather data.
11. **View Total Weather Records** – Display the total number of weather records.
12. **Exit** – Close the application.

## Weather Record Information

Each weather record contains the following information:

| Field | Description |
|---|---|
| Record ID | Unique ID for each record |
| Date | Date of the weather record |
| City | City name |
| Temperature | Temperature in Celsius |
| Humidity | Humidity percentage |
| Rainfall | Rainfall in millimetres |

## How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the Python file:

   `weather_data_analysis_tool.py`

5. Select an option from the main menu and follow the instructions.

## Limitations

- This project uses only built-in Python features.
- No external libraries are required.
- Weather records are stored in a list while the program is running.
- Data is not permanently saved. Records will be lost when the application closes.
